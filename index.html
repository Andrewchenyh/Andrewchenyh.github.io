The system

Pydantic validates structured AgentStep outputs and a typed tool registry. Python tools handle prices, historical volatility, options chains, SMA, EMA, RSI, MACD, and Bollinger Bands.

Redis supports caching, rate limiting, and session history. FastAPI streams agent activity over SSE; Docker Compose packages the services, and GitHub Actions runs CI.

A failure worth fixing

The agent once said an explicitly requested NVDA $200 put did not exist. The options tool was only searching near the current stock price.

I traced the request through the agent and tool path, then preserved explicit strikes in tool arguments so the user’s constraint survived execution.

Evaluation scope: 10 golden queries, with automated contract checks and an additional LLM-as-judge score. These results describe this benchmark, not every possible investment question.

The retrieval pipeline

Section-aware extraction and sentence-aware chunks (approximately 500 tokens, with 64-token overlap) preserve useful context. OpenAI text-embedding-3-small powers dense retrieval; BM25 adds lexical matching, followed by Reciprocal Rank Fusion and reranking.

Metadata filters scope retrieval by ticker, fiscal year, section, and filing type. FastAPI exposes /ingest, /retrieve, /chat, and /health.

Evaluation as a feedback loop

I iterated from dense retrieval to BM25, hybrid RRF, and reranking, measuring required-evidence hits, Fact Recall@5, Full Coverage@5, Context Precision@5, and MRR. A source-grounded evaluation set pairs 45 required facts with 110 human-verified quotes; a deterministic resolver generates chunk mappings and fingerprints for reproducible checks.

The evaluation currently focuses on Microsoft’s 2023 10-K / 10-K/A. It is a focused regression benchmark; I do not claim the results generalize to all filings.
